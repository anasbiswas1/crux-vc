# crux-vc

CRUX-VC: a construct-Rashomon audit of predictive explanations and selective venture screening on public Crunchbase event data.

Master plan: `docs/`. Analysis notebooks run in order `notebooks/00`-`20` and read every path from `config/paths.py`. Raw data lives under `data/` and is never committed; `protocol/` holds the frozen source manifest, ledgers, and design-lock files that stand in for it.
